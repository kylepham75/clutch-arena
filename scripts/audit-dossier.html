1.1 The Core Problem & The Promised Dream Outcome

Higher-education exam preparation is broken across four key failure modes:

  • Slide Bloat & Cognitive Exhaustion: Students receive 150–300 slide decks packed with dense text, mathematical proofs, and decorative bullet points. Highlighting slides creates a "fluency illusion" of mastery without encoding memories.
  • The 48-Hour Exam Panic: Most university students cram 48 to 72 hours before midterms and finals. Traditional spaced-repetition tools (e.g., Anki) take hours of tedious manual card creation, while recurring monthly SaaS platforms experience catastrophic 15%–25% churn the day exams conclude.
  • AI Hallucinations in High-Stakes Subjects: Generic AI quiz apps invent formulas, fabricate accounting rules, and lack slide-level attribution, destroying user trust in Finance, Economics, STEM, Pre-Med, and Law.

The Promised Dream Outcome: "Make every minute count." Convert 150+ slides of academic bloat into a gamified active-recall tournament and an 85% noise-reduced, 2-page exam cheat sheet equipped with KaTeX formulas, boundary rules, and verbatim slide citations in under 60 seconds.

1.3 The 6 Proprietary Defensibility Moats

1. Cross-Family Blind AI Verification Pipeline lib/ai/verify-questions.ts

Generator models (Anthropic Claude Haiku 5.5) and verifiers (DeepSeek v4.1 Flash or GPT-4o-mini) are strictly segregated by family (assertCrossFamilyVerifier). The verifier receives candidate questions stripped of answer keys and must blind-solve them from source text alone. Questions with ambiguous options or hallucinations are purged before user display.

2. Deterministic Financial Mathematics Solvers lib/math/finance-solver.ts

Exact algorithmic solvers for TVM, Perpetuities, Annuities, DDM, Bond Pricing, YTM, NPV, IRR, WACC, and CAPM. Generates mathematically realistic distractors (omitted tax shields, wrong compounding periods) rather than uncalibrated LLM guesses.

3. Domain Rule Verification Packs lib/notes/domain-rule-packs.ts

Three compiled academic rule packs (corporateFinanceValuationPack, statisticsRiskReturnPack, workingCapitalAccountingPack) that lint formulas to prevent circular growth rates, wrong Bessel sample variances (n-1 vs n), and denominator additions (R+g vs R-g).

4. Real-Time Cumulative COGS Degradation Ladder lib/pricing/tiers.ts#L194-L305

Monitors cumulative user USD spend against tier revenue. Transitions automatically across four operational modes (full -> gentle -> hard -> halted), throttling OCR and caching question sets to prevent runaway negative margins.

5. Dual-Engine Realtime Multiplayer party/arena.ts

Sub-30ms PartyKit edge WebSockets with automatic Next.js SSE fallback. Includes AI bots (lib/multiplayer/bot-ai.ts) so low-occupancy rooms remain competitive.

6. Zero-DB Pack URL Portability lib/game/pack-transfer.ts

Compresses entire study packs into Base64 URL hashes (#pack=...), enabling viral distribution across class chats with zero database storage costs.

Part 2: Pre-Launch Readiness Audit

/founder-launch & /founder-ops

The codebase was subjected to an exhaustive architectural audit for commercial launch readiness. Findings are classified into P0 Critical Blockers (block immediate launch), P1 High-Risk (must fix prior to paid ad spend), and P2 Polish.

1. Missing Terms of Service & Privacy Policy Pages P0 Critical Blocker
A scan of all App Router routes reveals zero pages or modals for Terms of Service (/terms) or Privacy Policy (/privacy). The platform processes student-uploaded documents via external AI gateways (OpenRouter, Anthropic, DeepSeek, Google) and takes financial transactions via PayOS. Operating a commercial SaaS without published Terms and Privacy documentation violates payment gateway agreements and international consumer data regulations.
Required Remediation: Create app/terms/page.tsx and app/privacy/page.tsx. Formally document that uploads are processed with Zero Data Retention (zdr: true), never used to train public LLMs, and processed via PayOS VietQR. Link both in app/layout.tsx, pricing-modal.tsx, and auth-dialog.tsx.
2. Rest-of-World (USD) Card Checkout Rail Missing P0 Critical Blocker
While lib/pricing/tiers.ts defines USD pricing ($4.99, $9.99, $29.00), components/pricing/pricing-modal.tsx only connects to PayOS VietQR. When an international user clicks "Verify Payment", the application displays a generic error message ("Payment not yet confirmed by the server") and falls back to an early-access lead form. Non-Vietnamese users cannot complete self-serve transactions.
Required Remediation: Either integrate Polar.sh / LemonSqueezy / Stripe for ROW users, or immediately lock the launch UI to Vietnam with an explicit banner: "Early Access live in Vietnam (VietQR). Global credit card payments launch next month."
3. Production PartyKit Host Unconfigured in Environment P0 Critical Blocker
In .env.local, NEXT_PUBLIC_PARTYKIT_HOST is blank. In hooks/use-arena-room.ts, when PartyKit is unconfigured, the app falls back to Server-Sent Events (/api/arena/rooms/[code]/stream) backed by an in-memory Map in lib/multiplayer/room-manager.ts. On Vercel serverless functions, state is partitioned across lambdas; students attempting to join the same study arena from different devices will be placed into disjointed rooms and experience connection errors.
Required Remediation: Deploy the PartyKit room script (npm run party:deploy), set NEXT_PUBLIC_PARTYKIT_HOST=clutch-arena.<account>.partykit.dev in Vercel environment variables, and configure PARTYKIT_INTERNAL_SECRET.
4. Distributed Rate Limiting Degrades to Memory Without Redis P1 High-Risk
In lib/rate-limit.ts, if UPSTASH_REDIS_REST_URL or KV_REST_API_URL is missing, the system falls back to an in-memory sliding window. On Vercel serverless cold starts, memory resets and is unshared between instances, enabling malicious actors to bypass rate limits and exhaust AI token budgets through parallel requests.
Required Remediation: Verify that Upstash Redis credentials are added to production environment variables, and add a check preventing production builds if Redis is unconfigured.
5. Lack of Automated Account Deletion (GDPR "Right to be Forgotten") P1 High-Risk
The user profile UI (components/auth/user-profile-button.tsx, auth-dialog.tsx) and API routes lack an account deletion flow. If a user requests complete account and document removal, manual database intervention is required.
Required Remediation: Implement DELETE /api/auth/account to cascade-delete records from user_study_packs, user_runs, profiles, and Supabase auth.
6. Missing Centralized Application Error Monitoring (Sentry) P1 High-Risk
Unhandled client/server exceptions rely on console.error and the basic error boundary (app/error.tsx). There is no centralized error tracking (Sentry/Axiom). Transient AI gateway 502s or PayOS webhook failures will occur silently in production.
Required Remediation: Install @sentry/nextjs to monitor production exceptions, AI generation timeouts, and payment webhook failures.
7. Missing Social OpenGraph Tags, Sitemap & Robots.txt P1 High-Risk
app/layout.tsx lacks OpenGraph (og:image) and Twitter Card tags. Links shared in student Discord or Zalo groups will render as plain text without preview cards. No app/sitemap.ts or app/robots.ts exists.
Required Remediation: Add rich social metadata in app/layout.tsx pointing to /clutch-arena-full.png and scaffold app/robots.ts and app/sitemap.ts.
